# Transit Watch

A mobile-first transit reliability platform. MARTA is the first supported
transit agency.

## Applications

- `transit-watch-api/` — Phoenix API, transit-feed ingestion, PostgreSQL database,
  and reliability analytics
- `transit-watch-mobile/` — React Native / Expo rider mobile application

## Status

Early development. The initial goal is to ingest Atlanta's MARTA GTFS schedule and
real-time data, then expose rider-focused reliability information in the mobile
application.
